# QbitX UI Design System & Visual Tokens (RC-1)

Complete specification of QbitX's modern glassmorphism design language.

---

## 1. Color Palette & Visual Accents

- **Background**: `bg-background` (`slate-950` in dark mode, `slate-50` in light mode).
- **Cards & Containers**: `bg-card` (`slate-900/80` dark, `white` light) with `backdrop-blur-md` and `border border-border`.
- **Student Accents**: `sky-500` / `cyan-500` (`#0ea5e9`).
- **Mentor Accents**: `purple-600` / `indigo-600` (`#9333ea`).
- **Admin Accents**: `amber-500` / `orange-500` (`#f59e0b`).

---

## 2. Typography & Radius Tokens

- **Font Heading**: Inter / Outfit (`font-heading font-extrabold`).
- **Border Radius**:
  - Cards: `rounded-3xl` (`1.5rem`)
  - Badges & Buttons: `rounded-2xl` / `rounded-xl` (`1rem` / `0.75rem`)
  - Pills: `rounded-full` (`9999px`)
- **Responsive Breakpoints**:
  - `sm`: 640px
  - `md`: 768px
  - `lg`: 1024px
  - `xl`: 1280px
